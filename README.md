# AI From Scratch

A practical, beginner-friendly collection of lessons, code examples, and exercises for learning artificial intelligence and AI engineering.

Start with the fundamentals, explore the examples, and work through the exercises at your own pace. The material is designed for people new to AI; some later examples may require basic Python knowledge.

## Start here

### AI vs. Machine Learning vs. Deep Learning

Learn how AI, machine learning, and deep learning relate to one another through a rule-based spam-filter example. Explore why an exact-match rule can miss a suspicious email and how a learning-based approach differs.

- **Watch the lesson:** [AI vs. Machine Learning vs. Deep Learning](https://youtu.be/1YDNWFDSLgU)
- **Explore the materials:** [Lesson notes, Python example, and exercise](week-01-ai-fundamentals/README.md)

### How Machine Learning Models Learn

Train and evaluate a text classifier using labeled email examples and a fixed test set.

- **Watch the lesson:** [How Machine Learning Models Learn](https://youtu.be/bJuibUsvf2s?si=RH26q3ViE8-hMHgL)
- **Explore the materials:** [Lesson notes, dataset, Python code, and exercises](week-02-how-models-learn/README.md)

### How Large Language Models Work

Explore tokenization, next-token probabilities, and text generation with a small pretrained model running locally on your laptop.

- **Watch the lesson:** [How Large Language Models Work: Tokens and Text Generation](https://youtu.be/2D8bazmxERg)
- **Explore the materials:** [Lesson notes, Python code, setup, and exercises](week-03-how-llms-work/README.md)

### Prompt Engineering: Design, Test, and Evaluate AI Instructions

Use the OpenAI API to compare four prompting configurations across 50 labeled support tickets. Measure classification accuracy, format compliance, and failures.

- **Explore the materials:** [Lesson notes, 50-ticket dataset, Python evaluation, and exercises](week-04-prompt-engineering/README.md)

### How Neural Networks Learn: Backpropagation

Train a small neural network on XOR to see forward propagation, loss, backpropagation, and parameter updates in action.

- **Explore the materials:** [Lesson notes, Python experiment, setup, and exercises](week-05-neural-networks-backpropagation/README.md)

## How to use this repository

1. Open a lesson folder and read its README for the concepts and prerequisites.
2. Review the included code and run it locally using the instructions in that folder.
3. Complete the exercise, then modify the example to test your understanding.
4. Compare the behavior you observe with the explanation in the lesson.

Each lesson folder is intended to keep its explanations, code, and exercises together so you can revisit or reproduce the examples without following a publishing schedule. Check individual folders for setup instructions and required files.

## A note on the examples

Examples are educational and intentionally simplified.
